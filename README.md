# 豆包无水印复制下载工具

一款Chrome浏览器扩展，允许用户从豆包网站上轻松获取无水印图片。支持一键复制或下载图片，无需手动处理水印，适合设计师、创作者和一般用户获取高质量原始图片资源。

作者：陈杨   微信：jinb701

## 主要功能

- **右键菜单操作**：在豆包网站的图片上右键点击，即可唤出自定义菜单
- **无水印复制**：一键将无水印图片复制到剪贴板，方便粘贴到其他应用
- **无水印下载**：直接下载原始无水印图片到本地，保持完整分辨率
- **智能识别**：自动识别豆包网站的各种图片展示形式
- **用户友好**：简洁的界面和操作流程，无需复杂设置

## 安装方法

### 手动安装（开发版）

1. 下载此仓库的代码并解压
2. 打开Chrome浏览器，进入扩展管理页面：`chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择解压后的插件文件夹

## 使用方法

1. 安装插件后，访问豆包网站
2. 在需要获取无水印版本的图片上点击鼠标右键
3. 在弹出的菜单中选择：
   - **无水印复制**：将图片复制到剪贴板
   - **无水印下载**：将图片下载到本地

## 隐私说明

本插件尊重并保护用户隐私：

- **本地处理**：所有操作完全在浏览器本地执行，不会向任何外部服务器发送数据
- **无数据收集**：不会收集、存储或传输个人信息、浏览历史或图片内容
- **最小权限**：仅请求必要的权限，用于识别和处理图片
- **开源透明**：代码完全开源，用户可以审查所有行为

## 常见问题

**Q: 为什么有时右键菜单不显示？**  
A: 请确保您正在豆包网站上，并且鼠标右键点击的是图片元素。某些特殊结构的页面可能需要刷新后再试。

**Q: 复制图片失败怎么办？**  
A: 某些浏览器可能限制剪贴板访问。此时插件会显示手动复制对话框，按提示操作即可。

**Q: 支持哪些豆包图片格式？**  
A: 插件支持豆包网站上的各种图片格式，包括AI生成的图片、作品展示等。
